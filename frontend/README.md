# ⚡ HackMatch — Frontend

Frontend client for **HackMatch (Hackathon Team & Skill Matching Platform)** built with **React 19**, **Vite**, and **Tailwind CSS v4**.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app will run locally at: **`http://localhost:5173`**

---

## 📦 Key Libraries

- **React 19** + **Vite 8**: Frontend framework and build tooling.
- **Tailwind CSS v4** (`@tailwindcss/vite`): Modern styling and design system.
- **React Router v7**: Client-side routing and protected routes.
- **Lucide React**: Developer icons.
- **Axios**: Configured API client with JWT interceptors.
